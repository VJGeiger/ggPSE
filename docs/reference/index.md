# Package index

## Core plotting

Main periodic table functions

- [`ggPSE()`](https://vjgeiger.github.io/ggPSE/reference/ggPSE.md) :
  Plot a periodic table with a continuous value overlay
- [`ggPSE_theme()`](https://vjgeiger.github.io/ggPSE/reference/ggPSE_theme.md)
  : Apply a pre-built theme to a periodic table plot
- [`ggPSE_save()`](https://vjgeiger.github.io/ggPSE/reference/ggPSE_save.md)
  : Save a periodic table plot with sensible defaults

## Encodings

Additional visual encoding layers

- [`ggPSE_bubble()`](https://vjgeiger.github.io/ggPSE/reference/ggPSE_bubble.md)
  : Plot a periodic table with bubble size encoding
- [`ggPSE_bar()`](https://vjgeiger.github.io/ggPSE/reference/ggPSE_bar.md)
  : Plot a periodic table with in-tile bar encoding
- [`ggPSE_donut()`](https://vjgeiger.github.io/ggPSE/reference/ggPSE_donut.md)
  : Overlay donut or pie charts on a periodic table

## Annotations

Overlay annotations on tiles

- [`ggPSE_badge()`](https://vjgeiger.github.io/ggPSE/reference/ggPSE_badge.md)
  : Overlay country-of-origin badges on a periodic table

## Analytical views

Period, group and trend profiles

- [`ggPSE_profile()`](https://vjgeiger.github.io/ggPSE/reference/ggPSE_profile.md)
  : Plot a single period, group, or f-block row with a trend line

## Interactivity

Interactive plots via ggiraph

- [`ggPSE_interactive()`](https://vjgeiger.github.io/ggPSE/reference/ggPSE_interactive.md)
  : Interactive periodic table with hover tooltips

## Data

Built-in element datasets

- [`ggpse_elements`](https://vjgeiger.github.io/ggPSE/reference/ggpse_elements.md)
  : Full element properties table
- [`ggpse_grid`](https://vjgeiger.github.io/ggPSE/reference/ggpse_grid.md)
  : Minimal element grid for plotting

## Package

- [`ggPSE-package`](https://vjgeiger.github.io/ggPSE/reference/ggPSE-package.md)
  : ggPSE: Periodic Table Visualization Using ggplot2
